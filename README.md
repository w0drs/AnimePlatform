# Anime Encyclopedia Platform

Микросервисная веб-платформа для просмотра информации об аниме, управления пользовательским избранным, комментирования и получения персонализированных рекомендаций на основе гибридного подхода: контентной фильтрации (векторные представления описаний) и коллаборативной фильтрации (матричное разложение ALS).

Проект реализован в рамках дипломной работы и развёрнут на домене `kuronami.fun`.

---

## Обзор архитектуры

Приложение построено по принципу микросервисов с выделенными независимыми модулями, каждый из которых отвечает за изолированную бизнес-область. Взаимодействие между сервисами осуществляется по HTTP/REST внутри общей Docker-сети. Внешние запросы маршрутизируются через Caddy, который выполняет функции обратного прокси, терминации TLS и ограничения частоты запросов.

## Ключевые возможности

### Контент
- Каталог аниме с постерами, описаниями, метаданными (жанры, тематики, демографика, студии, рейтинги, трейлеры)
- Полнотекстовый поиск и многофакторная фильтрация по году, типу, рейтингу, жанру, теме, демографике и студии
- Лента новостей индустрии аниме с разделением на превью и полный контент
- SEO-оптимизированный серверный рендеринг (SSR) страниц

### Пользовательская активность
- Регистрация и аутентификация с двухтокеновой схемой (access / refresh JWT)
- Ролевая модель: пользователь, модератор, администратор
- Управление избранным (добавление / удаление аниме)
- Система комментариев к аниме и новостям с поддержкой ответов и мягкого удаления (`is_deleted`)

### Рекомендательная система
Платформа реализует два независимых механизма, работающих параллельно:

1. **Контентная фильтрация (Content-based)** — на странице каждого аниме отображается блок «Похожие аниме». Алгоритм преобразует описание, жанры, темы и демографические атрибуты в векторное представление с помощью Sentence-BERT. Поиск ближайших соседей выполняется в Qdrant по косинусной близости с гибридной функцией оценки, включающей коэффициент Жаккара для категориальных признаков. Метод эффективно решает проблему «холодного старта»: новый тайтл рекомендуется сразу после добавления в базу.

2. **Коллаборативная фильтрация (Collaborative filtering)** — на главной странице авторизованного пользователя отображается блок «Рекомендации для вас». Алгоритм ALS (Alternating Least Squares) анализирует матрицу взаимодействий «пользователь — аниме» (implicit feedback на основе избранного), выявляет латентные факторы и предлагает тайтлы, которые оценили похожие пользователи. Модель обучается офлайн и периодически обновляется по расписанию.

## API эндпоинты (краткая спецификация)
Content Service (:8001)
- GET /anime — список аниме с пагинацией и фильтрацией
- GET /anime/{anime_id} — детальная информация об аниме
- POST /anime, PUT /anime/{anime_id}, DELETE /anime/{anime_id} — управление контентом (модератор / админ)
- GET /news, GET /news/{news_id}, GET /news/slug/{slug} — лента и детальная страница новостей

Auth & Users Service (:8002)
- POST /auth/register, POST /auth/login — регистрация и вход
- POST /auth/refresh, POST /auth/check — управление сессиями
- GET /user/profile/me, PUT /user/profile/me — профиль пользователя
- POST /user/favorites/{anime_id}, DELETE /user/favorites/{anime_id} — избранное
- GET /comments/anime/{anime_id}, POST /comments/anime/{anime_id} — комментарии к аниме
- GET /comments/news/{news_id}, POST /comments/news/{news_id} — комментарии к новостям

Recommendations Engine (:8003)
- GET /recommend/anime/{anime_id} — гибридные похожие аниме по ID
- GET /recommend/text — поиск похожих аниме по текстовому запросу
- GET /recommend/collaborative/{user_id} — персональные рекомендации на основе ALS
