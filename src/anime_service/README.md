# Anime Service

Сервис для управления аниме и новостями в базе данных PostgreSQL. Предоставляет REST API для CRUD операций и поиска.

## Функционал

### Аниме
- **CRUD операции** — создание, чтение, обновление, удаление аниме
- **Список с пагинацией** — просмотр всех аниме с постраничным выводом
- **Фильтрация** — по году, типу (TV/Movie/OVA), минимальному рейтингу
- **Детальный просмотр** — получение аниме вместе с жанрами, темами, демографикой и студиями
- **Поиск** — по названию или синопсису

### Новости
- **CRUD операции** — создание, чтение, обновление, удаление новостей
- **Список с пагинацией** — просмотр всех новостей с постраничным выводом
- **Публикация** — возможность включать/отключать публикацию новости
- **Детальный просмотр** — получение превью и полного содержания
- **Доступ по slug** — получение новости по текстовому идентификатору (slug)

## Зачем это нужно

- **Единый источник данных** — централизованное хранение информации об аниме и новостях
- **Универсальный API** — один сервис обслуживает оба типа контента
- **Гибкий поиск** — пользователи могут находить аниме по разным критериям
- **Контент-менеджмент** — администрирование новостей с контролем публикации
- **Связанные данные** — автоматическая подгрузка жанров, тем и студий для аниме
