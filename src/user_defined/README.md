# Users-defined Service

Сервис управления комментариями, избранным и пользователями с JWT-авторизацией.

## 🏗️ Технологии

- **PostgreSQL** — хранение пользователей, комментариев, избранного
- **Redis** — хранение сессий и метаданных сессий
- **JWT** — авторизация

## 🔐 Авторизация

Защищенные эндпоинты используют `AuthMiddleware`, который проверяет JWT-токен и валидность сессии в Redis.

**Формат заголовка:** `Authorization: Bearer <token>`

## 📍 Эндпоинты

### Аутентификация (публичные)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/auth/login` | Вход в систему |
| POST | `/auth/register` | Регистрация |
| POST | `/auth/refresh` | Обновление токенов |
| POST | `/auth/check` | Проверка авторизации |
